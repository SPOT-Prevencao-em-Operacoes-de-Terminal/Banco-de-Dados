# Banco de Dados — SPOT

Repositório acadêmico desenvolvido para a disciplina de **Banco de Dados**, como parte do projeto **SPOT — Sistema de Prevenção Operacional de Terminais**.

Este repositório contém a estrutura e os scripts responsáveis pela **modelagem, criação e gerenciamento do banco de dados** utilizado pelo projeto SPOT.

## Objetivo

O objetivo deste repositório é desenvolver o banco de dados responsável por armazenar e organizar as informações utilizadas pelo sistema SPOT.

O banco foi desenvolvido para permitir o armazenamento dos dados das empresas, usuários, máquinas, componentes e métricas de monitoramento, possibilitando que essas informações sejam posteriormente utilizadas pela aplicação.

## Banco de Dados

O projeto utiliza o **MySQL** como sistema gerenciador de banco de dados.

A estrutura foi desenvolvida utilizando um modelo de banco de dados relacional, com tabelas relacionadas por meio de **chaves primárias e estrangeiras**.

## Integração com o projeto SPOT

O banco de dados é uma das partes responsáveis pelo funcionamento do SPOT.

A aplicação utiliza os dados armazenados para registrar e consultar informações relacionadas ao monitoramento da infraestrutura computacional dos terminais.

Posteriormente, esses dados podem ser utilizados pela aplicação web para apresentar as informações coletadas e o histórico das métricas monitoradas.

## Projeto acadêmico

Este repositório faz parte do desenvolvimento acadêmico do **projeto SPOT — Sistema de Prevenção Operacional de Terminais**.

O desenvolvimento permite aplicar conceitos de **modelagem de dados, SQL, banco de dados relacional, relacionamentos entre tabelas, integridade referencial e manipulação de dados utilizando MySQL**.
